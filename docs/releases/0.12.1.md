gitd 0.12.1: fewer git processes for each workspace.

## Faster workspaces from a template, on every system

A workspace made from a template now starts 5 git processes instead of 9 when no branch is
asked for, and 6 instead of 8 when one is:

- A pool's default branch is remembered until the pool is fetched again, instead of being
  read by git for every workspace.
- The default branch is not checked again as a name: git set it as the pool's HEAD. A
  branch someone asks for still is.
- A workspace's branch and its `origin` are set in one `update-ref` transaction.
- How a workspace was made is answered from what gitd just did, not read back.

Measured on GitHub's runners, ten workspaces of OCA/web: on macOS 0.10 s a workspace
instead of 0.17 s; on a Windows Dev Drive about 0.76 s of gitd's own time instead of about
1.1 s, with git processes costing 42 ms there.
