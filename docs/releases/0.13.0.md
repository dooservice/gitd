gitd 0.13.0: a client for Go.

## The Go client

- `github.com/dooservice/gitd/client`: the client gitd's own command line and MCP server
  are built on, now public. `go get github.com/dooservice/gitd/client@v0.13.0`.
- `client.Open(client.Options{})` finds the socket as the Python client does: the one
  given, then `$GITD_SOCKET`, then the system's default. A gitd on the network is called
  at its address, with the key naming the caller's tenant and an authority to trust.
- Every call of the contract, with the contract's own messages; `client.Reason(err)` reads
  why gitd refused one. See its [README](../../client/README.md).
- It runs on Linux, macOS and Windows, as gitd does.

## Releases

- Each release is also tagged `v<version>` on the same commit, which is how Go finds a
  module's versions; the module proxy is asked for it as the release is made.

## Upgrading

Nothing to do. The contract is unchanged. A program that imported
`github.com/dooservice/gitd/internal/client` could not, as Go keeps `internal` to gitd
itself. Clients: `pip install gitd==0.13.0`, `npm install gitd-client@0.13.0`.
